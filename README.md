# Tripy — планировщик путешествий

Tripy — учебная информационная система для создания путешествий, хранения мест и билетов, учёта расходов и ведения фотогалереи. Интерфейс выполнен на русском языке в светлом стиле с фирменным жёлтым акцентом.

## Технологии

- PHP 8.x и серверные сессии;
- MySQL/MariaDB, PDO и подготовленные запросы;
- HTML5, CSS3, JavaScript без фреймворков;
- файловое хранение обложек, билетов и фотографий с метаданными в MySQL.

Node.js, Composer, Docker и сборка на сервере не требуются.

## Основные файлы

```text
index.php                       главная и статистика из MySQL
trips.php                       список путешествий
trip.php                        внутренняя страница путешествия
gallery.php                     фотографии, сгруппированные по поездкам
actions/trip-save.php           создание и редактирование путешествия
actions/photo-save.php          безопасная загрузка фотографии
api/trip-actions.php            места, билеты и расходы
download-ticket.php             контролируемая выдача билета
includes/bootstrap.php          сессия, PDO, CSRF и общие функции
includes/trip-repository.php    чтение данных для страниц
database/schema.sql             пустая схема из шести таблиц
database-check.php              временная безопасная проверка PDO и схемы
config/config.example.php       шаблон настроек без секретов
uploads/                        пользовательские файлы
```

Согласованные тестовые путешествия и записи удалены из источника данных. `database/schema.sql` не создаёт поездки, места, билеты, расходы или фотографии. После установки пользователь начинает с пустого приложения.

## Настройка MySQL на InfinityFree

Схема уже импортирована, поэтому повторно запускать `database/schema.sql` не нужно.

1. В `/htdocs/config` создайте файл `config.php` как копию `config.example.php`.
2. Заполните `MYSQL_HOST`, `DATABASE_NAME`, `DATABASE_USER` и `DATABASE_PASSWORD` значениями из панели InfinityFree.
3. Храните реальные реквизиты только в `config/config.php` на сервере. Этот файл исключён из Git и финального архива.
4. Для первой проверки временно установите `enable_db_check => true`.
5. Откройте `https://tripi-lab.freedev.app/database-check.php`.
6. После сообщения об успешной проверке сразу верните `enable_db_check => false`.

`config/config.php` не входит в архив публикации и исключён через `.gitignore`. Каталог `config` дополнительно закрыт от HTTP-доступа файлом `.htaccess`.

До появления авторизации все записи принадлежат `default_user_id = 1`. Это временное ограничение архитектурного этапа, а не полноценная многопользовательская защита.

## InfinityFree

Укажите хост, имя базы и пользователя из раздела MySQL Databases в панели InfinityFree; порт обычно `3306`. Убедитесь, что PHP может создавать файлы в `uploads/covers`, `uploads/tickets` и `uploads/photos`. Билеты не открываются прямой ссылкой: их выдаёт `download-ticket.php` после проверки владельца.

Диагностическая страница проверяет подключение, обязательные столбцы, CRUD путешествия, вставку места, билета, расхода и фотографии, а также каскадное удаление. Все проверочные записи выполняются внутри транзакции и откатываются, поэтому в базе не остаётся тестовой информации.

## Запуск через XAMPP на Windows

1. Скопируйте проект в `C:\xampp\htdocs\tripi`.
2. Запустите Apache и MySQL в XAMPP Control Panel.
3. Импортируйте `database/schema.sql` через `http://localhost/phpmyadmin`.
4. Создайте `config/config.php` по шаблону. Для стандартного XAMPP обычно используются `host=localhost`, `user=root`, пустой пароль и имя созданной базы.
5. Откройте `http://localhost/tripi/`.

Через встроенный сервер PHP:

```bash
php -S localhost:8000
```

Если `php` не распознаётся, используйте XAMPP или полный путь:

```bash
C:\xampp\php\php.exe -S localhost:8000
```

## Реализовано

- логотип с графитовой планетой и отдельной надписью Tripy в раскрытом меню;
- меню «Главная», «Путешествия», «Галерея» и окно «Информация о проекте»;
- пустые состояния без фиктивных пользовательских данных;
- создание и редактирование путешествия с сохранением прежней обложки;
- постоянное хранение мест и отметки посещения;
- загрузка, редактирование, закрепление и удаление билетов;
- транзакционная связь стоимости билета с единственным расходом;
- создание, редактирование и удаление расходов, пересчёт бюджета;
- загрузка фотографий и единый источник для галереи и главной;
- PDO, подготовленные запросы, CSRF и серверная MIME-проверка.

## Ограничения текущего этапа

- авторизация ещё не реализована, используется один технический владелец;
- реальное подключение считается завершённым только после заполнения `config/config.php`, импорта схемы и проверки повторного чтения на конкретном сервере;
- защита билетов опирается на будущую авторизацию: сейчас проверяется технический владелец сессии;
- редактирование подписи фотографии пока не добавлено; удаление фотографии доступно внутри путешествия;
- автоматические тесты и локальная проверка PHP требуют установленного PHP 8.x и тестовой базы.
