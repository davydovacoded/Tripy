# Tripy — планировщик путешествий

Tripy — учебная информационная система для создания путешествий, хранения мест и билетов, учёта расходов и ведения фотогалереи. Интерфейс выполнен на русском языке в светлом стиле с фирменным жёлтым акцентом.

## Технологии

- PHP 8.x и серверные сессии;
- MySQL/MariaDB, PDO и подготовленные запросы;
- HTML5, CSS3, JavaScript без фреймворков;
- файловое хранение обложек, билетов и фотографий с метаданными в MySQL.

Node.js, Composer, Docker и сборка на сервере не требуются.

## Основные файлы

```text
index.php                       главная и статистика из MySQL
trips.php                       список путешествий
trip.php                        внутренняя страница путешествия
gallery.php                     фотографии, сгруппированные по поездкам
actions/trip-save.php           создание и редактирование путешествия
actions/photo-save.php          безопасная загрузка фотографии
api/trip-actions.php            места, билеты и расходы
download-ticket.php             контролируемая выдача билета
includes/bootstrap.php          сессия, PDO, CSRF и общие функции
includes/trip-repository.php    чтение данных для страниц
database/schema.sql             пустая схема из шести таблиц
database-check.php              временная безопасная проверка PDO и схемы
config/config.example.php       шаблон настроек без секретов
uploads/                        пользовательские файлы
```
